# بوت تنزيل الوسائط لـ Telegram

مستودع تجريبي لبوت Telegram يستقبل رابط ويب من المستخدم، ويحاول تنزيل الوسائط باستخدام `yt-dlp` ثم إرسال الملف إلى المحادثة. هذا الوصف مستند إلى الشيفرة الموجودة؛ **ليس تأكيدًا بأن البوت يعمل أو أن جميع الوظائف مكتملة**.

> **الحالة:** لم يتضمن المستودع README عند مراجعته. الفحص قراءة ساكنة فقط؛ لم تُشغّل الشيفرة أو الاختبارات ولم تُثبّت الاعتماديات. توجد تناقضات في بنية الوحدات ونقطة الدخول، لذلك لا يُعتمد على خطوات التشغيل أدناه بوصفها مجرّبة.

## ما يظهر في المصدر

- معالجة رسائل الروابط التي تبدأ بـ `http://` أو `https://`، ومحاولة تنزيل الوسائط عبر `yt-dlp` وإرسالها إلى Telegram وفق نوع الملف.
- حد حجم مضبوط في الإعدادات مقداره **50 ميبيبايت**. هذا حد يطبقه المصدر، وليس ضمانًا لقبول Telegram لكل ملف أو نجاح التنزيل.
- نصوص وواجهات بثلاث لغات ظاهرة في ملفات اللغات: العربية والإنجليزية والفارسية.
- قاعدة SQLite تتضمن بيانات تعريف المستخدمين واللغة، وإعدادات وضع الصيانة وقائمة الحظر.
- توجد في واجهة الإدارة شيفرة لعرض إحصاء المستخدمين، وتفعيل الصيانة وإيقافها، والحظر وإلغاء الحظر، والبث للمستخدمين.

تحتوي النصوص وقائمة الإعدادات على أسماء منصات متعددة وادعاءات دعم واسعة. وجود الاسم أو رسالة المساعدة لا يثبت أن التنزيل يعمل لتلك المنصة؛ يعتمد ذلك على الرابط وإتاحة المحتوى وتوافق `yt-dlp`، ولم يُختبر هنا. لا يُثبت المصدر ادعاء دعم أكثر من ألف موقع.

## بنية الملفات

- `main.py`: يحتوي على معالجين وأوامر Telegram واستدعاء `run_polling()` عند تشغيل الملف مباشرة.
- `config.py`: إعدادات تستخدم `python-dotenv` وتعرّف `BOT_TOKEN` و`ADMIN_ID`، إلى جانب اسم قاعدة البيانات ومجلد التنزيل وحد الحجم.
- `requirements.txt`: قائمة الاعتماديات وإصداراتها المثبتة.
- `database.py`, `languages.py`, `helpers.py`, `admin.py`, `start.py`, `download.py`, `downloader.py`, `menu.py`: ملفات قاعدة البيانات واللغة والمساعدة والإدارة والتنزيل.

**تنبيه بنيوي:** توجد أكثر من صيغة للتنفيذ داخل المستودع. يستورد `start.py` و`admin.py` و`download.py` وحدات من `utils` و`services`، لكن هذين المجلدين غير موجودين في الملفات المفحوصة؛ كما توجد ملفات مساعدة وتنزيل في المستوى الأعلى. لذلك لا يمكن تأكيد أن هذه الوحدات قابلة للاستيراد معًا. كذلك لا تتطابق إعدادات `config.py` مع الإعدادات المنفصلة الموجودة في `main.py`. يلزم توحيد نقطة الدخول ومصادر الإعداد والاستيرادات قبل اعتبار المشروع جاهزًا للتشغيل.

## المتطلبات والإعداد

يعلن `requirements.txt` عن الاعتماديات التالية: `python-telegram-bot`, `yt-dlp`, `aiofiles`, `python-dotenv`, `requests`, و`pillow`، مع إصدارات محددة فيه. لا يحدد المستودع إصدار Python المطلوب أو نظام تشغيل مدعومًا.

يعرض المصدر الاسمين `BOT_TOKEN` و`ADMIN_ID` في `config.py` كمتغيري بيئة، لكن `main.py` يحتوي إعدادات مستقلة ولا يعتمد على هذا الملف بحسب الاستيرادات الظاهرة. لذلك لا يكفي ضبط متغيرات البيئة وحده لتأكيد إعداد آمن أو صحيح؛ يجب أولًا إزالة الإعدادات الثابتة وتوحيد طريقة قراءتها. لا تضع رمز البوت أو أي قيمة سرية في README أو في مستودع عام.

إذا عولجت التناقضات وأُعدّت بيئة Python مناسبة، فهذه أوامر مقترحة اعتمادًا على ملف الاعتماديات ونقطة الدخول المعلنة، **غير مجرّبة**:

```bash
python -m pip install -r requirements.txt
python main.py
```

لا تنفذ أمر التشغيل قبل تدوير بيانات الاعتماد المكشوفة ومعالجة مشاكل الإعداد والبنية ومراجعة المخاطر الموضحة أدناه. لم يُجرَ بناء أو تشغيل أو اختبار لهذا المشروع في هذه المراجعة.

## البيانات والخصوصية

- يخزن المصدر معرّف مستخدم Telegram واسم المستخدم والاسمين الأول والأخير واللغة في SQLite باسم `bot_database.db`، إضافة إلى إعدادات الحظر والصيانة.
- يستخدم المصدر مجلد `downloads` لتنزيلات الوسائط؛ سياسة الاحتفاظ والتنظيف والاستعادة غير موثقة، ولا ينبغي افتراض حذف جميع الملفات في كل حالات الفشل.
- يرسل البوت الرابط المقدم إلى `yt-dlp` لجلب محتواه، ثم يرسل الملف إلى Telegram. قد تتصل عملية التنزيل بالموقع الذي يشير إليه الرابط. لا ترسل روابط خاصة أو بيانات لا تملك إذنًا لمعالجتها.
- قبل النشر، وثّق مدة الاحتفاظ بالبيانات والملفات، وأمّن ملفات قاعدة البيانات والتنزيلات، ووفّر آلية واضحة للحذف وإدارة الوصول.

## تنبيه أمني وقانوني

**تتضمن ملفات المصدر إعداد اعتماد Telegram ثابتًا، كما يوجد ملف إعداد اسمه `معلومات سرية.env` يُحتمل أن يحوي بيانات اعتماد.** تعامل مع أي اعتماد موجود في المستودع على أنه مكشوف: أبطله أو دوّره فورًا، وافحص سجل Git والنسخ المنشورة، ولا تنسخ محتوى الملف أو تضع أسرارًا في إعدادات متتبعة. لا تُشغّل النسخة الحالية قبل إزالة الاعتمادات الثابتة وتوحيد تحميلها من مصدر أسرار آمن.

كذلك، قبول روابط يرسلها المستخدم وتشغيل `yt-dlp` عليها قد يعرّض الخادم لمحتوى ضار أو روابط داخلية غير مقصودة أو استهلاك زائد للموارد. عند تطوير المشروع، قيّد مصادر الروابط والشبكة، وحدد حدودًا للوقت والحجم والتزامن، واعزل عمليات التنزيل، وتعامل مع الملفات غير الموثوقة بحذر. راجع صلاحيات الإدارة والبث قبل إتاحة البوت للآخرين.

استخدم الأداة فقط للمحتوى الذي تملك حق تنزيله أو لديك إذن صريح به، واحترم حقوق النشر وشروط خدمات Telegram والمنصات المستهدفة والقوانين المحلية. هذا المشروع لا يثبت امتلاك المستخدم لهذه الحقوق ولا يضمن إتاحة المحتوى أو مشروعية تنزيله.
